# 🔥 웍웍! (Wok Wok!)

푸드트럭 안에서 손님을 받으며 볶음밥을 만드는 3D 시뮬레이터입니다.
핵심은 **직접 하는 웍질** — 웍을 끌어서 흔들면 재료가 물리적으로 구르고 떠오르며,
너무 세게 흔들면 웍 밖으로 튀어 나갑니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 로 빌드 (상대 경로라 Electron / Capacitor 에 그대로 올릴 수 있음)
```

## 플레이 방법

로비에서 **이어서 하기**(저장된 회차부터) 또는 **처음부터**를 고릅니다. 진행 상황은 브라우저에 저장됩니다.

한 회차는 **🧪 레시피 연구 → 🚚 장사 → 📊 결과 확인** 순서로 진행되고, 결과 확인 때마다 새 재료가 하나 열립니다. 화면이 바뀔 때마다 (첫 로딩, 연구 시작, 장사 시작, 장사 마감, 로비로) 모션 그래픽 전환 화면이 나옵니다.

### 레시피 연구 (집 주방)
- **기름통**을 꾹 누른 채 웍 위로 끌고 가서 흔들면 기름이 나옵니다 (흔드는 세기만큼, 가리키는 곳에 떨어짐). 기름 적정량은 모든 레시피 공통(30ml)입니다. 기름을 안 두르거나 적정량의 절반보다 적으면 재료가 웍에 눌어붙어 웍질해도 뜨지 않고, 더 빨리 탑니다.
- 재료를 골라 넣고 웍질로 볶은 뒤 **맛보기**를 누릅니다. 재료마다 익는 속도가 달라서, 느리게 익는 재료부터 넣어야 다 같이 맞게 익습니다. 대부분의 레시피는 대파(파기름)부터 넣습니다.
- 넣은 재료가 하나라도 덜 익었거나 너무 익었거나 탔으면, 또는 기름이 적정량이 아니면 맛볼 수 없습니다.
- 맛보기는 횟수 제한이 없습니다. 넣은 재료 종류가 레시피 북의 조합과 같으면 그 레시피를 찾고, 아니면 가장 가까운 레시피를 기준으로 "몇 가지가 어울리는지 / 몇 가지가 더 필요한지" 반응이 나옵니다.
- 첫 회차는 파 계란 볶음밥을 만드는 **단계별 튜토리얼**입니다 (기름 두르기 → 대파 넣기 → 대파 볶기 → 계란 넣기 → 계란 익히기 → 밥 넣기 → 다 같이 볶기 → 맛보기). 웍 상태를 보고 자동으로 다음 단계로 넘어가고, 눌러야 할 버튼·기름통·웍을 강조하며, 순서가 틀리거나 타면 경고합니다. 찾기 전에는 장사하러 갈 수 없습니다.

### 재료와 레시피
- 재료 10개(밥 포함): 밥 · 대파 · 계란으로 시작하고, 장사가 끝날 때마다 김치 → 햄 → 양파 → 당근 → 새우 → 베이컨 → 치즈 순서로 열립니다.
- 같은 재료를 여러 번 넣을 수 있습니다: 1번 적게 · 2번 기본 · 3번 많이.
- 레시피 13개는 각자 정해진 넣는 순서와 양이 있습니다. 찾기 판정은 재료 종류만 보고, 순서와 양은 장사 때 별점에 반영됩니다.

### 장사 (푸드트럭)
- 손님은 찾은 레시피만 주문합니다. 주문서에 재료가 순서대로, 넣은 횟수/정석 횟수로 표시됩니다.
- 재료 구성 · 양 · 넣은 순서 · 재료별 익힘 · 고르게 익은 정도 · 탄 재료 · 기름 양 · 남은 양으로 별점과 가격이 정해지고, 웍질 보너스가 붙습니다.
- 재료를 높이 띄우면 웍질 보너스가 쌓입니다 (상한 없음).

## 화면 디자인

밤 포장마차 컨셉의 UI: 남색 밤 배경 위 반투명 짙은 패널, 등불 주황 강조, 핵심 버튼(이어서 하기 · 맛보기 · 내놓기)은 고추 빨강, 주문서 · 튜토리얼 · 결과 · 레시피 북은 크림색 종이. 제목은 Black Han Sans, 본문은 IBM Plex Sans KR (Google Fonts). 아이콘은 이모지 대신 스티커형 SVG(64 그리드 · 3px 외곽선 · 평면 2톤)를 씁니다. 데스크톱(가로)과 휴대폰(세로) 배치가 따로 있습니다. 휴대폰 세로 화면에서는 위아래 패널 사이의 빈 공간을 재서, 웍(과 들고 있는 기름통 · 손님)이 그 안에 들어오도록 카메라 확대와 화면 위치를 자동으로 맞춥니다.

## 그래픽 품질

화면 오른쪽 위의 **그래픽** 버튼(로비와 게임 화면, 휴대폰처럼 좁은 화면에서는 로비에만)을 누를 때마다 자동 → 낮음 → 중간 → 높음 순서로 바뀝니다. 자동은 휴대폰·태블릿이나 작은 화면이면 중간, 아니면 높음입니다. 선택은 브라우저에 저장됩니다.

| 단계 | 해상도 배율 | 그림자 | AO | 안티에일리어싱 |
| --- | --- | --- | --- | --- |
| 낮음 | 1 | 끔 | 끔 | SMAA |
| 중간 | 최대 1.5 | 1024 | 끔 | MSAA 2x + SMAA |
| 높음 | 최대 2 | 2048 | 켬 | MSAA 4x + SMAA |

## 화면 크기와 상관없는 같은 손맛

- **웍 끌기**: 손가락 이동(px)을 '웍 자리에서 화면 1px 이 몇 m 인지'로 바꿔, 어느 화면에서나 손가락이 화면 속 웍을 같은 비율로 끈다 (`dragGain`, 기본 0.75 = 예전 PC 감각).
- **기름 흔들기**: 최근 0.1초 동안 포인터가 움직인 거리로 속도를 재고 m/s 로 바꿔 판정한다 (터치 샘플링 빈도와 무관). 기준은 `oilShakeMinMs`.
- **화면 구도**: 휴대폰 세로 · 가로(높이 520px 이하)에서는 패널 사이 빈 곳에 웍이 들어오도록 카메라를 맞춘다. 휴대폰 가로는 재료 · 버튼을 오른쪽 세로 단에 두는 배치를 따로 쓴다.
- **시간**: 물리는 1/240초 고정 간격, 한 프레임 최대 0.1초까지 따라잡아 10fps 이상이면 게임 시간이 실제 시간대로 흐른다.
- **자동 품질**: 게임 중 평균 fps 가 40 아래면 높음 → 중간 → 낮음 → 해상도 80%씩(최소 60%) 단계적으로 낮춘다.
- **확인**: `scripts/feel-check.cjs` 가 여러 기기 크기에서 같은 손동작의 결과를 표로 비교한다 (파일 머리 주석에 실행 방법).

## 디버그 패널

화면 왼쪽의 **🛠 디버그** 버튼(또는 `` ` `` 키)으로 엽니다.

- 물리, 익힘/탐, 웍 조작, 웍질 보너스, 채점, 하루/손님, 그래픽 수치를 슬라이더나 숫자 입력으로 바로 바꿀 수 있습니다. 기본값과 다른 항목은 노랗게 표시됩니다.
- **📋 수치 복사**: 전체 수치를 한 번에 복사합니다 (맨 위에 바뀐 항목 요약 포함).
- **수치 붙여넣기**: 복사해 둔 내용을 붙여넣으면 그대로 적용됩니다.
- 바꾼 수치는 이 브라우저에 저장되어 새로고침해도 유지됩니다.
- 기본값은 `src/tuning.ts` 의 `DEFAULTS` 에 있습니다.

# 🔥 웍 트럭 (Wok Truck)

푸드트럭 안에서 손님을 받으며 볶음밥을 만드는 3D 시뮬레이터입니다.
핵심은 **직접 하는 웍질** — 웍을 끌어서 흔들면 재료가 물리적으로 구르고 떠오르며,
너무 세게 흔들면 웍 밖으로 튀어 나갑니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 로 빌드 (상대 경로라 Electron / Capacitor 에 그대로 올릴 수 있음)
```

## 플레이 방법

1. 손님이 오면 상단 **주문서**의 재료를 아래 버튼으로 웍에 넣습니다.
2. 웍을 **누른 채로 끌어서**(마우스 / 터치) 흔들어 볶습니다.
   - 바닥에 닿은 재료가 빨리 익고, 위에 얹힌 재료는 덜 익습니다. 너무 오래 볶으면 탑니다.
   - 흔들어서 재료를 띄우면 골고루 익고, **웍 안으로 다시 떨어진 재료가 높이 떴던 만큼 웍질 보너스**가 쌓입니다 (5cm 이상부터, 상한 없음).
   - 세게 흔들면 재료가 웍 밖으로 쏟아져 양이 줄어듭니다 (쏟아진 재료는 보너스 없음).
3. 익힘 게이지가 초록 구간에 오면 **내놓기**(Space). 재료 구성 · 남은 양 · 익힘 · 고르게 익은 정도 · 탄 재료로 별점과 가격, 팁이 정해지고, 웍질 보너스 100%마다 품질 가산점 +20%(별점은 최대 5개)와 가격의 30%만큼 보너스 금액이 붙고, 보너스 금액은 상한 없이 계속 쌓입니다.
4. 하루(2분 30초)가 끝나면 정산 후 다음 날로 넘어가며, 날이 갈수록 메뉴가 늘고 손님의 인내심이 줄어듭니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.ts` | 게임 루프, 주문/채점/하루 진행, HUD |
| `src/wok.ts` | 웍 모델과 입력을 따라가는 키네마틱 움직임(위치·기울임) |
| `src/physics.ts` | 재료 입자 물리(웍 곡면 충돌·마찰, 입자 간 충돌, 가열/탐), 인스턴스 렌더링 |
| `src/scene.ts` | 트럭 내부, 밤 거리 풍경(네온·가로등·전구 줄), 화구 불꽃, 김 |
| `src/look.ts` | 카툰 셰이딩·외곽선 변환, 블룸 후처리, 웍질 불길·불티 효과 |
| `src/customers.ts` | 손님 모델과 행동 |
| `src/ingredients.ts` | 재료 · 레시피 데이터 |
| `src/audio.ts` | Howler.js 효과음 (에셋 없이 코드로 합성) |

스택: TypeScript · Vite · Three.js · Howler.js

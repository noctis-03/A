# 🔥 웍 트럭 (Wok Truck)

푸드트럭 안에서 손님을 받으며 볶음밥을 만드는 3D 시뮬레이터입니다.
핵심은 **직접 하는 웍질** — 웍을 끌어서 흔들면 재료가 물리적으로 구르고 떠오르며,
너무 세게 흔들면 웍 밖으로 튀어 나갑니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 로 빌드 (상대 경로라 Electron / Capacitor 에 그대로 올릴 수 있음)
```

## 플레이 방법

로비에서 **이어서 하기**(저장된 회차부터) 또는 **처음부터**를 고릅니다. 진행 상황은 브라우저에 저장됩니다.

한 회차는 **🧪 레시피 연구 → 🚚 장사 → 📊 결과 확인** 순서로 진행되고, 결과 확인 때마다 새 재료가 하나 열립니다.

### 레시피 연구 (집 주방)
- 재료를 골라 넣고 웍질로 볶은 뒤 **맛보기**를 누릅니다. 재료마다 익는 속도가 달라서, 느리게 익는 재료부터 넣어야 다 같이 맞게 익습니다.
- 넣은 재료가 하나라도 덜 익었거나 너무 익었거나 탔으면 맛볼 수 없습니다 (횟수는 줄지 않음).
- 맛보기는 회차당 2번입니다. 넣은 재료 종류가 레시피 북의 조합과 같으면 그 레시피를 찾고, 아니면 가장 가까운 레시피를 기준으로 "몇 가지가 어울리는지 / 몇 가지가 더 필요한지" 반응이 나옵니다.
- 첫 회차는 파 계란 볶음밥을 안내에 따라 찾는 튜토리얼이고, 찾을 때까지 맛보기가 줄지 않습니다.

### 재료와 레시피
- 재료 10개(밥 포함): 밥 · 대파 · 계란으로 시작하고, 장사가 끝날 때마다 김치 → 햄 → 양파 → 당근 → 새우 → 베이컨 → 치즈 순서로 열립니다.
- 같은 재료를 여러 번 넣을 수 있습니다: 1번 적게 · 2번 기본 · 3번 많이.
- 레시피 13개는 각자 정해진 넣는 순서와 양이 있습니다. 찾기 판정은 재료 종류만 보고, 순서와 양은 장사 때 별점에 반영됩니다.

### 장사 (푸드트럭)
- 손님은 찾은 레시피만 주문합니다. 주문서에 재료가 순서대로, 넣은 횟수/정석 횟수로 표시됩니다.
- 재료 구성 · 양 · 넣은 순서 · 재료별 익힘 · 고르게 익은 정도 · 탄 재료 · 남은 양으로 별점과 가격이 정해지고, 웍질 보너스가 붙습니다.
- 재료를 높이 띄우면 웍질 보너스가 쌓입니다 (상한 없음).

## 디버그 패널

화면 왼쪽의 **🛠 디버그** 버튼(또는 `` ` `` 키)으로 엽니다.

- 물리, 익힘/탐, 웍 조작, 웍질 보너스, 채점, 하루/손님, 그래픽 수치를 슬라이더나 숫자 입력으로 바로 바꿀 수 있습니다. 기본값과 다른 항목은 노랗게 표시됩니다.
- **📋 수치 복사**: 전체 수치를 한 번에 복사합니다 (맨 위에 바뀐 항목 요약 포함).
- **수치 붙여넣기**: 복사해 둔 내용을 붙여넣으면 그대로 적용됩니다.
- 바꾼 수치는 이 브라우저에 저장되어 새로고침해도 유지됩니다.
- 기본값은 `src/tuning.ts` 의 `DEFAULTS` 에 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.ts` | 게임 루프, 로비/저장, 레시피 연구(맛보기), 장사(주문/채점), 결과·해금, HUD |
| `src/wok.ts` | 웍 모델과 입력을 따라가는 키네마틱 움직임(위치·기울임) |
| `src/physics.ts` | 재료 입자 물리(웍 곡면 충돌·마찰, 입자 간 충돌, 가열/탐), 인스턴스 렌더링 |
| `src/scene.ts` | 푸드트럭과 밤 거리, 집 주방(연구), 화구 불꽃, 김 |
| `src/tuning.ts` | 밸런스 수치 기본값과 디버그 패널 항목 정의 |
| `src/debug.ts` | 디버그 패널 (수치 조절 · 복사 · 붙여넣기) |
| `src/look.ts` | 카툰 셰이딩·외곽선 변환, 블룸 후처리, 웍질 불길·불티 효과 |
| `src/customers.ts` | 손님 모델과 행동 |
| `src/ingredients.ts` | 재료 10개 · 레시피 13개(넣는 순서와 양) 데이터 |
| `src/audio.ts` | Howler.js 효과음 (에셋 없이 코드로 합성) |

스택: TypeScript · Vite · Three.js · Howler.js
